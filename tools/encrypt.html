Encrypt the members data

This page runs entirely on your computer. Nothing is uploaded anywhere. It turns private.json (the calendar, photo album, contacts sheet, and document links) into private.enc, which is what gets published. Only someone with the pack password can read it.

  1. Paste the contents of private.json below (kept in the Pack 96 Website folder on Google Drive, never in GitHub).
  2. Type the pack password twice.
  3. Click Encrypt, then Download private.enc, and replace the private.enc file in the site folder.
  4. Commit and push. The site updates in about a minute.
